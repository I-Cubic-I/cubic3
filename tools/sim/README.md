# 규칙 시뮬레이터

메인 게임 규칙(카드 흐름, 토큰, 보상, 문양 능력, 연장전, 팀전)을 컴퓨터 플레이어로 수천 판 돌려 길이·연장전·역전 빈도·카드별 영향을 보는 도구다. 규칙을 바꿀 때마다 다시 돌려 확인한다.

## 실행

```
cd tools/sim
python3 run.py                      # 현재 확정 규칙으로 모드별 비교
python3 run.py --trials 5000        # 판 수 늘리기
python3 run.py --sk catchup_steal   # ♠K 방식 바꾸기
python3 run.py --no-stages          # 아이템을 처음부터 모두 넣기
python3 run.py --team4-picks 1      # 팀 4인 보상을 1인 1장으로
```

다른 조건은 `cubicsim.Game(...)`의 인자로 바꾼다(시작 손패, 상한, 토큰 비용, 덱 수, ♠K 방식, 아이템 투입 방식 등). 규칙 요약과 인자 설명은 `cubicsim.py` 맨 위 주석에 있다.

## 한계

- 플레이어는 탐욕형이다. 그 순간 가장 좋은 카드를 고르고, 앞을 내다보거나 블러핑하지 않는다.
- 미니게임은 "실력 + 운 (+ 아이템 효과)"로 순위만 정한다. 미니게임 종류는 구분하지 않아 ♣의 메인 효과(미니게임 판 조작)는 잴 수 없다.
- ♦Q는 사용 조건을 좁게 잡아 거의 쓰이지 않는다.
- 결과는 "규칙이 대략 어떤 방향으로 움직이는지"를 보는 용도다. 재미·체감은 시험 플레이로 확인한다.
