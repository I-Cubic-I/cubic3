# 시험판 (proto)

규칙 시험용 웹 시험판. 정식 디지털판이 아니다(겉모습·기술 스택은 나중에 다시 정한다).

- `web/index.html`: claude.ai 아티팩트로 게시하는 한 파일짜리 페이지. 공유 데이터(`db`의 `games/table` 문서 하나)에 테이블 상태를 통째로 저장하고, 모든 기기가 실시간으로 본다.
- 게시 주소: https://claude.ai/artifact/3mexLaLYA5W5YgapotjBuf (비공개. 친구는 공유 메뉴에서 **편집자**로 초대해야 상태를 바꿀 수 있다)

## 1차 범위 (2026-10-09)

- 개인전 2~5인(2·3인 트럼프 1벌, 4·5인 2벌). 한 기기에서 여러 자리를 조종하는 혼자 시험 모드.
- 메인 게임: 줍기(덱/버림 줄 끝)와 버리기, 토큰 만들기(3·4·5장, 연장전 3장), 아이템 능력 전부(♠ 공격과 ♥ 방어 6초 유예, ♥Q, ♦J·♦Q·♦K, ♣ 선언 5초), 손패 6장 정리, Q·K 단계 투입, 승리 판정, 4색 연장전, 큐빅 롤, 덱 소진 시 다시 섞기.
- 미니게임: 버티기, 폭탄 버튼(2명 결승), 눈치 경매. 라운드마다 메인 턴이 끝나면 미니게임 판 6칸을 이 셋으로 새로 채운다. 카드 미니게임은 재료 묶음(버림 줄 + 앞의 아이템 + 보충 + 덱 3장) 규칙대로.
- 보상: 미니게임 전에 2×인원+1장 진열, 순위대로 두 바퀴.

## 실물 규칙과 다르게 단순화한 곳

- 보상 고르기 동점: 동시 지목 대신 무작위 순서.
- ♠Q: 대상이 고르는 대신 해당 문양 숫자 카드 중 무작위.
- 문양 색은 임시(♠ 남색, ♥ 빨강, ♦ 주황, ♣ 초록).
- 숨긴 정보(손패 등)는 화면에서만 가린다(친구끼리 시험용).

## 엔진 점검

엔진(첫 번째 `<script>`)은 순수 함수라 node로 무작위 대국을 돌려 볼 수 있다. 2026-10-09: 2~5인 400판, 오류 없음, 카드 52장 보존 확인.
