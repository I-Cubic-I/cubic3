# 시험판 (proto)

규칙 시험용 웹 시험판. 정식 디지털판이 아니다(겉모습·기술 스택은 나중에 다시 정한다).

- `web/index.html`: claude.ai 아티팩트로 게시하는 한 파일짜리 페이지. 공유 데이터(`db`의 `games/table` 문서 하나)에 테이블 상태를 통째로 저장하고, 모든 기기가 실시간으로 본다.
- 게시 주소: https://claude.ai/artifact/3mexLaLYA5W5YgapotjBuf (비공개. 친구는 공유 메뉴에서 **편집자**로 초대해야 상태를 바꿀 수 있다)

## 1차 범위 (2026-10-09)

- 개인전 2~5인(2·3인 트럼프 1벌, 4·5인 2벌). 한 기기에서 여러 자리를 조종하는 혼자 시험 모드.
- 메인 게임: 줍기(덱/버림 줄 끝)와 버리기, 토큰 만들기(3·4·5장, 연장전 3장), 아이템 능력 전부(♠ 공격과 ♥ 방어 6초 유예, ♥Q, ♦J·♦Q·♦K, ♣ 선언(2차부터 규칙 설명 시간 전체)), 손패 6장 정리, Q·K 단계 투입, 승리 판정, 4색 연장전, 큐빅 롤, 덱 소진 시 다시 섞기.
- 미니게임: 버티기, 폭탄 버튼(2명 결승), 눈치 경매. 라운드마다 메인 턴이 끝나면 미니게임 판 6칸을 이 셋으로 새로 채운다. 카드 미니게임은 덱에서 뽑는다(재료 묶음 폐지). 미니게임 전에 버림 줄과 앞의 아이템을 덱에 섞는다. 줍기는 버림 줄의 아무 카드 1장.
- 보상: 미니게임 전에 2×인원+1장 진열, 순위대로 두 바퀴.

## 2차 (2026-10-10)

- 미니게임 8개: 버티기, 폭탄 버튼, 눈치 경매에 **풍선 불기, 선 가위바위보, 금고 털기, 몇 장이었지, 문양 경주** 추가(모두 2~5인). 라운드마다 이 중 6장을 뽑는다.
- **연출**: 미니게임 제목 카드, 주사위 굴림, 탈락 "펑!"과 화면 흔들림, 가위바위보·금고 수색 공개, 경매 입찰 공개, 정답 공개, 미니게임 순위, 토큰·공격·우승(색종이), 내 차례 알림, 풍선 부풀기·말 점프·카드 뒤집기. 엔진이 `S.fx`에 이벤트를 남기고 각 화면이 받아 재생한다(움직임 줄이기 설정이면 끔).
- 문양 색: ♠ 파랑, ♥ 빨강, ♦ 노랑, ♣ 초록(확정 색).
- **규칙 설명 시간**: 미니게임이 정해지면 규칙 카드를 띄우고, 모두 "준비 완료"를 누르면 시작. ♣는 그동안 언제든 쓸 수 있고, ♣로 미니게임이 바뀌면 준비 완료가 풀린다. 한 기기에서 여러 자리를 조종하면 내 자리를 한 번에 준비 완료.
- 문양 경주: 5칸.

## 실물 규칙과 다르게 단순화한 곳

- 보상 고르기 동점: 동시 지목 대신 무작위 순서.
- ♠Q: 대상이 고르는 대신 해당 문양 숫자 카드 중 무작위.
- 금고 털기: 경비원 화면에서 숨은 곳을 가리지만, 혼자 시험 모드(한 기기 여러 자리)에서는 다 보인다.
- 몇 장이었지: 넘기는 시각은 각 기기 시계 기준이라 기기마다 조금 어긋날 수 있다.
- 숨긴 정보(손패 등)는 화면에서만 가린다(친구끼리 시험용).

## 엔진 점검

엔진(첫 번째 `<script>`)은 순수 함수라 node로 무작위 대국을 돌려 볼 수 있다. 2026-10-09: 2~5인 400판, 오류 없음, 카드 52장 보존 확인. 2026-10-10: 미니게임 8개로 600판, 오류 없음, 카드 보존 확인. 화면은 헤드리스 Chromium(공유 데이터 대역)으로 미니게임별 캡처 확인.
