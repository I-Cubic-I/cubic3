# 마법사 캐릭터 그림 요청서 (이미지 생성 도구용 · 3D 변환용)

2026-10-15 작성. 아레나 미니게임의 마법사를 새로 만들기 위해, **그림 → 3D 자동 생성 도구(Tripo · Meshy 등)에 넣을 그림**을 이미지 생성 도구(ChatGPT 이미지 생성 · Gemini · Midjourney)로 뽑을 때 쓰는 요청 문구.
뽑은 3D 모델은 게임에서 3단 명암 · 굵은 잉크 윤곽선 · 색 단계 끊기 효과로 그림처럼 그린다(그림체는 게임 쪽에서 입힌다).

레퍼런스는 분위기 참고용으로만 쓰고 이미지 자체를 넣지 않는다(작가 서명이 있는 그림이 있어 상품용 결과에 직접 쓰면 위험).

## 3D 변환용 그림의 조건 (왜 이렇게 요청하는지)

- **평평한 색(무광, 그림자·하이라이트 거의 없이)**: 그림의 명암이 그대로 모델 색에 구워지면, 게임 조명과 겹쳐 얼룩진다. 붓 질감 · 도트 경계도 변환을 망치므로 이번 그림에서는 뺀다.
- **원근 없이 정면 · 옆 · 뒤가 같은 크기와 높이로**: 변환 도구가 앞뒤 모양을 맞춰 입체를 만든다.
- **팔을 몸에서 조금 떼고, 지팡이는 몸과 떨어져 곧게**: 붙어 있으면 한 덩어리로 녹아 붙는다.
- **흰 배경, 바닥 그림자 없음, 캐릭터 한 명만, 글씨 없음**.
- **큰 덩어리, 잘고 복잡한 장식은 최소**: 화면에서 작게 보이고, 변환 도구가 잔장식을 뭉갠다.

## 쓰는 순서

1. ChatGPT 이미지 생성(또는 Gemini)에 **상황 설명**을 붙여 넣는다.
2. **1번**으로 기준 마법사(정면)를 뽑고, 마음에 들 때까지 말로 고친다.
3. 같은 대화에서 **2번**으로 정면 · 옆 · 뒤 세 장(또는 한 장에 나란히)을 뽑는다.
4. 그림 → 3D 도구에 정면 한 장(도구가 여러 장을 받으면 세 장 모두)을 넣어 GLB 모델을 받는다.
5. 꾸미기 부품이 필요할 때 **3번**으로 부위만 따로 뽑아 같은 방법으로 변환한다.

## 상황 설명 (대화 맨 처음에 붙여 넣기)

```
나는 "Cubic³"라는 파티형 보드게임을 만들고 있어. 실물 보드게임과 PC·모바일·웹 디지털판을 함께 만든다.
디지털판에는 라운드마다 미니게임이 있고, 일부 미니게임은 "아레나"라는 3D 무대에서 진행된다.
아레나에서 각 플레이어(2~5명)는 작은 마법사 캐릭터로 등장한다(탑 꼭대기 주사위 피하기, 동굴 탐험, 산꼭대기 원소 마법 대결 등).

네가 그릴 그림은 "그림 → 3D 모델 자동 생성 도구"에 넣어 3D 모델을 만들기 위한 원본이야.
3D 모델은 게임 안에서 셀 셰이딩과 굵은 잉크 윤곽선으로 그려지니까, 그림 자체는 3D 변환이 잘 되도록 그려야 해.

캐릭터 조건:
- 키가 작고 다부진 노인 마법사(약 3등신). 몸보다 모자가 크고 존재감이 있다.
- 큰 코, 덥수룩한 흰 눈썹, 뾰족한 귀, 주름진 얼굴. 고집 세지만 정감 가는 인상.
- 넓은 챙의 고깔모자(챙이 처지고 끝이 꺾임), 땅에 닿을 듯한 망토, 크림색 튜닉, 가죽 허리띠와 주머니·물약병,
  가죽 장화, 울퉁불퉁한 나무 지팡이(끝에 수정).
- 나중에 모자 · 수염 · 지팡이 · 옷 · 색을 바꿔 끼울 수 있게 할 거라 부위가 서로 분명히 나뉘어 보여야 한다.
- 주 색(모자·망토)은 파랑 #2f5fc8. 나중에 빨강·노랑·초록·보라로도 바꾼다.
- 게임 화면에서는 작게 보이므로 실루엣이 분명하고, 큰 덩어리 위주로 잘고 복잡한 장식은 최소로.

3D 변환용 그림 규칙(꼭 지켜 줘):
- 평평한 색으로 칠하고 그림자·하이라이트·질감은 거의 넣지 않는다(무광, 고른 조명).
- 원근 없이(직교 투영처럼) 반듯하게. 흰 배경, 바닥 그림자 없음, 캐릭터 한 명만, 글씨 없음.
- 팔은 몸에서 조금 떼고, 지팡이는 몸과 떨어진 곳에 곧게 세워 한 손으로 쥔다.
- 망토와 수염이 팔·손·지팡이를 가리지 않게.
```

## 1. 기준 마법사 (정면 한 장)

```
위 조건으로 기본 마법사 한 명을 정면에서 전신으로 그려 줘. 똑바로 서서 팔을 몸에서 조금 뗀 자세,
오른손에 지팡이를 몸 옆으로 곧게 세워 쥔다.
기본 조합: 챙이 넓게 처지고 끝이 꺾인 고깔모자 / 콧수염과 허리까지 오는 긴 수염(끝을 가죽 끈으로 묶음) /
울퉁불퉁한 나무 지팡이(끝에 파란 수정) / 망토 + 크림색 튜닉 + 가죽 허리띠와 물약 두 병 / 가죽 장화. 주 색은 파랑.
```

## 2. 정면 · 옆 · 뒤 (3D 변환용 구상도)

```
방금 그린 마법사를 그대로 유지한 채 3D 변환용으로 정면 · 옆(오른쪽에서 본 모습) · 뒤 세 방향을 한 장에 나란히 그려 줘.
- 세 그림의 키 · 비율 · 발 위치 · 모자 끝 높이가 정확히 같게, 같은 바닥선 위에.
- 원근 없이 반듯하게, 평평한 색, 그림자 없음, 흰 배경, 글씨 없음.
- 자세는 세 그림 모두 같게(팔을 몸에서 조금 떼고 지팡이는 몸 옆에 곧게).
```

(변환 도구가 한 장씩 받는다면: "같은 조건으로 정면만 / 옆만 / 뒤만 따로 한 장씩 그려 줘")

## 3. 꾸미기 부품 (부위만 따로)

```
같은 마법사의 부품을 3D 변환용으로 하나씩 따로 그려 줘. 각각 흰 배경에 그 부품만, 정면에서, 평평한 색, 그림자 없음.
크기와 비율은 위 마법사에게 끼웠을 때와 같게.
- 모자: 처지는 넓은 챙 고깔 / 가죽 띠와 금색 네모 버클이 달린 고깔 / 끝이 뾰족한 두건
- 수염(콧수염 포함): 끝이 길게 뻗은 콧수염 / 허리까지 오는 긴 수염 / 가슴을 덮는 덥수룩한 수염
- 지팡이: 울퉁불퉁한 나무 + 작은 수정 / 곧은 막대 + 가죽 감개 + 갈퀴에 물린 큰 수정 / 위에서 두 갈래로 갈라진 가지
```

(옷 · 신발 변형은 몸통과 붙어 있어 부품으로 떼기 어려우므로, 기준 마법사가 정해진 뒤 따로 정한다)
