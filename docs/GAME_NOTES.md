# 기획 메모 (구상 단계)

큐빅 공방에서 분리한 "라운드 사이 미니게임" 구상을 독립 게임으로 설계한다. 세공판 없이 새로 만든다.

## 큐빅 공방에서 가져온 요소 (2026-10-08 사용자 지정)

- **트럼프 카드로 진행한다.** 카드의 숫자는 미니게임에서, 문양은 게임 고유의 용도로 쓴다.
- **버린 카드로 미니게임을 한다.** 게임 중 버려진 카드가 다음 미니게임의 재료가 된다.
- **보상이 순위별로 다르다.** 미니게임 순위에 따라 받는 보상이 달라진다.

## 플랫폼 방향 (2026-10-08 사용자 지정)

- **실물 보드게임과 PC·앱·웹 버전을 모두 낸다.**
- **실물 버전**: 메인 게임과 미니게임 모두 트럼프·주사위·동전·칩·손짓(동시 선택)·심리전으로 진행할 수 있어야 한다. 전용 기기·앱 없이 성립해야 한다.
- **PC·앱·웹 버전**: 실물 미니게임에 더해 키보드·마우스(모바일은 터치) 조작 미니게임을 추가한다.

## 이름 (2026-10-08)

- 저장소·작업명 임시: `cubic-party` (이름은 나중에 다시 논의)
- 제목에 사용자 닉네임 "cubic"이 들어가거나 자연스럽게 녹아 있기를 원함
- 나온 해석:
  - cubic = 정육면체 = 주사위 (구성물과 직접 연결)
  - cubic = 세제곱 → 무언가를 3세트 모으는 승리 조건 (사용자 아이디어, 본체 설계 후보)
- 제목 후보(참고): 큐빅 카지노, 큐빅 하우스, 큐빅 잭팟, 큐빅 카니발, 큐빅 아케이드, 큐빅 파티

## 지금까지 나온 조건

- 한 판 길이: 2인 15분, 4인 25분 안팎
- 미니게임: 짧은 게임 위주. 실물 손재주 게임(튕기기·쌓기 등)은 온라인 이식이 어려워 제외 권장 (미정)
- 디지털 조작 미니게임은 반응속도·정확도형이 될 가능성이 높으므로, 미니게임 실력만으로 승패가 갈리지 않게 보상 폭을 조절한다 (큐빅 공방에서 이어진 원칙)

## 큐빅 공방에서 논의된 미니게임 보상 규칙 (참고, 미확정)

- 동점은 같은 순위로 보고 각자 그 순위의 보상을 받는다. 다음 순위는 동점자 수만큼 건너뛴다 (1위가 둘이면 다음은 3위).
- 모두 동점이면 모두 1위 보상. 팀전 무승부면 모두 이긴 팀 보상.
- 보상 장수 후보: A 꼴찌 2장·순위당 +1 / B 1위 3장·나머지 2장 / C 1위 3·꼴찌 1·나머지 2. 중간 순위 경쟁이 필요한지 보고 결정.
- 미니게임 후보로는 가위바위보만 임시로 있었다.
